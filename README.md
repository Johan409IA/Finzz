# finzz

Gestor de gastos personales con categorias


### stack


| Capa | Tecnología |
| --- | --- |
| **Backend** | Fastify |
| **Base de datos** | PostgreSQL |
| **Autenticación** | Módulo de auth integrado de InsForge |
| **ORM** | Drizzle ORM |
| **Frontend** | SolidJS |
| **Validación** | Zod |
| **Estilos** | Tailwind CSS |
| **Gráficos** | Solid UI  |
| **Package manager / runtime** | Bun |
| **Deploy** | Frontend en Vercel, backend en Render |
